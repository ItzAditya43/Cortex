## Try it

Open the Cortex panel (`Ctrl+Shift+L` / `Cmd+Shift+L`) and ask:

> list the files here

Then something real:

> where is `activate` defined?

Cortex asks your editor's language server rather than grepping, so it finds
the actual definition. After it edits a file, it reads the real compiler
errors back automatically.

Useful commands: `/help`, `/init`, `/compact`.
